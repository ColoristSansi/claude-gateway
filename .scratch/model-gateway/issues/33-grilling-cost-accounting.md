# 成本统计口径

Type: grilling
Status: resolved
Blocked by: —

## Question

用量统计要显示成本，价格从哪来、怎么换算、怎么展示？

要定：

1. **价格来源与优先级**：models.dev 的 cost 字段（输入 / 输出 / 缓存读 / 缓存写四种价）、手工覆盖、还是两者并用？优先级怎么排（票 02 已定 models.dev 的 `npm` 只能当预设先验，价格是不是同样待遇）？拿不到价格的模型显示什么——留空、显示 0、还是标「未知」？
2. **币种**：models.dev 报的是美元。界面直接显示美元，还是换算人民币？换算的话汇率从哪来（随包内置 / 联网取）、多久更新一次、离线怎么办？
3. **展示粒度**：概览页与日志页各自显示到哪一层（单次请求 / 按虚拟模型 / 按上游 / 按天）？缓存命中的 token 怎么计价（缓存读价 vs 输入价）？四个家族槽位共用同一个真实模型时，成本按槽位还是按上游归集？

## 背景

- 已解析：[票 02](02-research-provider-apis.md)（models.dev 的数据形状与可信度）、[票 11](11-design-stack-storage-and-observability.md)（存储与可观测：日志默认只记元数据、保留 7 天）、[票 08](08-design-destination-and-scope.md)（用量统计要做）。
- 原型已经在 `request_log` 里落库 `input_tokens` / `output_tokens` / `cache_read`（票 26 / 票 30），所以本票只定「价与展示」，不定采集。
- spec §9 记录了日志与保留策略；本票的结论要回写进去。

## Answer

（2026-10-15，与用户逐轮定案，全部经用户确认）

### 1. 价格来源与优先级

- **优先级：手工覆盖 > models.dev 快照 > 未知**。手工填过的条目**锁定**，导入/刷新不覆盖；models.dev 刷新只改未锁定值。
- **models.dev 数据随包内置一份快照** + 设置页一个**手动刷新**按钮（联网拉一次，失败静默沿用旧快照，不自动重试、不启动时自动拉）。
- **手工价挂「上游 × 真实模型」的目录条目上**（与票 23 的 `upstream_models` 同粒度）；models.dev 只负责填初值。同一个真实模型走不同中转可以不同价。
- **手工四项价各自可填、可留空**：输入 / 输出 / 缓存读 / 缓存写；留空的项回退 models.dev，再没有就是未知。界面标出每一项的实际来源。
- **拿不到价格显示「未知」**，**不计入总额**；另给一行「N 次请求无价格 / N 次请求 token 未知」，不显示 0、不留空。

### 2. 币种

- **库内一律以美元为锚**（models.dev 的 `cost.*` 是每百万 token 美元价）；换算只发生在显示层。
- **界面人民币为主**：汇率是**随包内置初值 + 设置页可手改，不联网刷新**。
- **用量页可手动切美元**（与上游账单对账用），概览与日志跟随当前选择。
- 金额**保留两位小数**；不足 ¥0.01 显示 `<¥0.01`。

### 3. 计费冻结（改价不追古）

- **请求时按当时价算好 `cost_usd` 存库**（`request_log` 加一列；当时没价就留空）。
- 之后手工改价或刷新 models.dev 快照，**不重算历史**。对外展示的人民币按**当前汇率**换算，所以改汇率会让历史人民币数字跟着变，改价不会。
- **上游没回 usage（token 为空）**：标「token 未知」，**成本不计**，不用本地估算反算。

### 4. 缓存计价

- `cache_read` 用 models.dev 的**缓存读价**；缺这个价则**退输入价**。
- `cache_write` **本期不计**——`request_log` 没有这列（票 30 未采集），实现阶段补采集列后再按缓存写价计。这是一处**已知缺口**，不是遗漏。

### 5. 展示粒度

- **概览页**：今日 + 近 7 天汇总；两个维度（按虚拟模型 / 按上游）。
- **用量与成本页**：时间范围 **今日 / 近 7 天 / 近 30 天 / 全部 / 自定义区间**（日边界按本机本地时区自然日，自定义区间的明细按天聚合）× 三个维度（客户端 / 上游 / 虚拟模型）+ 按天明细表。
- **日志页**：每行带**单次请求成本**（未知则标未知）。

### 6. 归集口径

- **按虚拟模型归集**（四个家族槽位名各自记账，普通虚拟模型同理）；**上游只作另一个维度**，不合并。

### 7. 界面入口（票 17 的 7 页不增设）

- **模型与映射页**：目录条目上一颗「价格」按钮（与票 23 的粒度一致）。
- **设置页**：models.dev 快照刷新按钮 + 汇率手改。

### 落地面

- spec §9「用量与成本」段与 §9 表草案（`upstream_models` 加手工价四列、`request_log` 加 `cost_usd`、`settings` 加汇率与快照刷新时间）；spec §10 第 3 / 6 / 7 条补三处界面入口与展示口径。
- 实现阶段的缺口：`request_log` 补 `cache_write` 采集列 + 缓存写价（与票 30 第 8 格同批）。
