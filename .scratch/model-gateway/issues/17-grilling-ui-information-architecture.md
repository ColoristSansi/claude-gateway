# 前端信息架构与交互

Type: grilling
Status: resolved
Blocked by: —

## Question

七个页面（概览、上游、模型与映射、客户端、日志与调试、用量与成本、设置）各自放什么、操作路径怎么走？用户不会编程，界面必须让「加一个上游 → 绑定家族槽位 → 一键切客户端」这条主路径最短。

## 需要定下来的

1. 加上游的向导步骤：从 models.dev 选供应商 → 预填 baseUrl 与协议 → 填 key → 拉 `/v1/models` 勾模型。哪一步可以跳过？
2. 家族槽位的绑定界面：四个槽位怎么展示上游与真实模型，如何避免「配置完不知道生效没有」（要有连通性自检按钮）。
3. 客户端卡片的状态表达：已指向本网关 / 未配置 / 配置被用户手改过，三种状态怎么区分。
4. 日志与调试页的默认视图与「打开 body 记录」的位置（默认关闭，要显眼说明隐私影响）。
5. 出现错误时的措辞与下一步引导（用户不读代码）。

## Answer

2026-10-14 与用户四轮弹窗对话定案（全程中文）。导航仍是 **7 页侧栏**，不合并、不增设页面。

**总纲 · 主路径**：由**概览页顶部的三步清单**串起「加上游 → 绑槽位 → 切客户端」。就绪判据 = ① 上游：至少一条已保存且自检通过；② 槽位：四行都绑定且探针通过；③ 客户端：三个客户端至少一个「已生效」。**首启不另做向导**，概览清单就是引导。

### 1. 概览页

- 顶部三步清单（未就绪高亮、点进对应页）；其下网关状态与端口、今日用量、最近错误（折叠区）。
- 动作两个：「一键把可用客户端都切到网关」（已生效的跳过；Desktop 切完提示需完全退出重启）、三步全绿后的「跑一次端到端验收」。
- 端到端验收 = 用 **haiku 槽位**发一条非流式最短请求；结果卡列出上游 / 状态码 / 耗时 / 首字延迟，失败时套错误模板 +「复制诊断」，并跳到该请求的日志详情。
- 有任何阻断性问题时，概览在侧栏上显示红点。

### 2. 上游页（四步向导）

1. 选供应商——从 models.dev 选一家，预填 baseUrl 与协议倾向；**可跳过**（直接手填 baseUrl）。
2. 填 baseUrl 与 key；允许先保存未验证。
3. 拉 `/v1/models` 勾选模型——**可跳过**，留「稍后继续」；上游没有 `/v1/models` 时（如千问的 Anthropic 端点）允许手工填模型 ID。
4. **自检并保存**（强制）——发一条最短真实请求过认证与路径，显示结果与原始错误。

上游列表每行：名称、baseUrl、协议、上次自检结果、「被 N 个槽位 / 虚拟模型使用」（可展开）。删除仍被引用的上游时弹窗列出引用处，要求先改绑或确认「一并删除那些绑定」。凭据只在这里管。

### 3. 模型与映射页

- 顶部**客户端标签**：全局 / Claude Desktop / Claude Code / Codex，默认「全局」；槽位表与虚拟模型列表随标签切换——这就是「每客户端可覆盖」的入口。
- 四个家族槽位固定四行：**槽位 | 上游 | 真实模型 | 协议 | 测试**。测试按钮发一条非流式 `max_tokens:1` 探针走真实链路（与 Claude Desktop 自身探针同形），回 ✓/✗ + 耗时 + 原始错误。
- 协议列必须显示（票 09：协议记在虚拟模型上）；**它能否在表内手改、候选取值从哪来，属[票 23](23-design-provider-table-granularity.md) 范围，本票不定**。
- 槽位表下方是普通虚拟模型列表：名称 | 上游 | 真实模型 | 协议 | 用途；**Codex 标签下这张列表就是它的模型目录**（`model_catalog_json` 由此生成）。

### 4. 客户端页

- 三张卡片，四态徽章：未配置 / 已生效 / **值不匹配** / 已回官方。状态在**每次进入页面时实读配置文件比对**得出，不缓存（缓存会撒谎）。
- 卡片内可折叠的「当前值 vs 期望值」对照表，不匹配项标黄；「值不匹配」给两个动作：以网关配置覆盖、或保留我的修改。
- 动作：一键切换 / 一键还原 /（Desktop 另有 1P↔3P 开关）。Desktop 卡片常驻提示：**配置改完必须完全退出并重开 Desktop 才生效**（Desktop 不做热重载）。卡片同时显示检测到的客户端版本与配置文件绝对路径。

### 5. 日志与调试页

- 默认元数据表格，时间倒序 50 条；筛选项：客户端 / 上游 / 虚拟模型 / 成功或 4xx、5xx / 仅看错误；顶部搜索框匹配模型名与请求 ID（不搜 body）。
- 点开一条 → 右侧详情抽屉四段：概要（模型 / 上游 / 耗时 / 首字延迟 / token / 成本）、请求体与响应体（仅在 body 记录开启时有）、帧时间轴（每帧时间戳 + 事件类型 + 摘要，可展开原文，可切「原始 SSE 文本」）、错误信息（模板 + 可展开的原始 JSON）。
- 「记录完整 body」开关在页面右上角，默认关；开启时弹一次隐私确认（说明会明文存本机 SQLite、保留 7 天）；开启后默认 **1 小时自动关闭**。设置页里是同一个开关。

### 6. 用量与成本页

维度切换（按客户端 / 上游 / 模型）+ 时间范围（今天 / 7 天 / 30 天 / 自定义）；主体是花费、请求数、token 的图表 + 明细表；**价格缺失的模型单独标「无价格」，不静默算成 0**。成本口径（价格来源、币种与展示）仍待后续票据。

### 7. 设置页

端口、开机自启、托盘行为、日志保留期与 body 开关（与日志页同一个）、数据库位置与「打开目录」、导出 / 导入（默认不含明文密钥）、关于与版本。**凭据不放这里。**

### 8. 系统托盘

右键：显示主窗口 / Claude Desktop 1P↔3P 快切 / 网关状态（运行中 · 端口）/ 打开日志目录 / 退出。左键单击开窗口，图标随状态变色。

### 9. 故障态（网关未运行 / 端口被占用）

- 所有页面顶部常驻横幅「网关未运行 · 端口 8787」+ 主按钮「启动网关」；数据页显示等待状态，**配置类页面仍可编辑**（用户可以先改配置再启动）。
- 端口被占用：横幅改成明确报错 +「换端口」按钮，点击时探测一个空闲端口自动预填，**由用户确认后写入**（不静默换端口，与票 11 一致）。换端口成功后自动重写所有「已生效」客户端的地址并提示「已同步 N 个客户端」（Desktop 提示重启），未生效的客户端不动。
- 侧栏徽标：上游项显示未通过自检的条数，客户端项显示未生效的个数。

### 10. 错误表达与诊断

- 统一模板：**发生了什么 + 可能原因 + 一个主按钮 + 复制诊断**，原始 JSON 可展开（用户选「1+2」）。例：上游 401 →「上游拒绝了这份凭据」+「这家上游可能对这个接口要求另一种密钥」+ 主按钮「去上游页检查凭据」。
- 出现位置三处：概览「最近错误」折叠区、操作当场的内联提示（卡片 / 表格行内）、日志详情；复制诊断只在前两者与日志详情上，概览不重复放。
- 复制诊断内容：应用与客户端版本、网关端口与运行状态、上游配置的脱敏形式（地址 + 密钥掩码 + 协议 + quirks）、错误原文、相关请求的元数据；**不含密钥明文，也不含请求 / 响应 body**。

### 11. 危险操作确认

改用户文件或删数据的动作（写入客户端配置、一键还原、删上游、清空日志）统一走二次确认弹窗：列出将改动的文件绝对路径与备份路径，主按钮写明动作（「写入并备份」「还原到安装时」）；不提供「下次不再问」。

### 遗留与依赖

- 槽位表「协议」列的可编辑性与候选取值 → [票 23](23-design-provider-table-granularity.md)。
- 三个客户端在**未登录**官方账号时能否只靠网关地址与凭据工作（本机 Claude Code 与 Codex 都未登录）→ 新开调研票据 [未登录态下能否只用网关凭据](24-research-client-login-state.md)；卡片文案等它的结论。
- 多语言与无障碍仍留在 map 的「Not yet specified」。

### 12. 上游页拉取提示的补充（票 35，2026-10-15）

只改原 §2「上游页」里「拉模型」那一步与上游列表的列，**导航与主路径不变**：

- 上游列表在「上次自检结果」之外补「**上次拉取时间**」与「**拉取警告角标**」（上游报的端点路径反查不到 wire 时亮，下次成功拉取清除）。
- 拉取结果三态：**成功**（勾选列表带可用 wire 徽章，手改条目锁定）/ **该上游不提供模型发现**（404/405 或 200 但零条 → 软提示「请手填模型 ID」+ 手填入口，**不报红**）/ **失败**（其他非 2xx、超时、断网 → 错误模板 + 「手工添加模型」按钮 + 「重试」按钮，就在向导内联新增，条目按 `manual` 锁定）。
- 拉取 **20 秒超时**，不自动重试（失败后由用户点「重试」）。
- **重拉失败保留旧条目**，提示「沿用上次结果（时间）」；只有成功拉取才覆盖。
- 拉取用上游 `default` 凭据（没有 `default` 而有多份时，在拉取这一步下拉选）。
- **这两类提示不计入侧栏「未通过自检的上游数」**，也不影响概览三步清单的就绪判据——原 §9 的徽标口径不变（判据只看自检）。
- opencode 只拉**带凭据**那份目录（19 条），采信票 35 的实测：无凭据那份是未过滤全量目录，勾了必 403 `Model access is disabled`。
